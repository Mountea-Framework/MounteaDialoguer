# Native package validation checkpoint

Owner: native_validation. 2026-09-30. No renderer changes or rebuild; no commits or publishing performed by this worker.

`npm run validate:native-package` validates the already packaged application on the host OS. It automatically resolves standard Electron Builder unpacked paths for Windows, Linux and macOS (including arm64); `MOUNTEA_PACKAGED_EXECUTABLE` overrides the path. `MOUNTEA_EXPECTED_PLATFORM` and `MOUNTEA_EXPECTED_ARCH` assert actual Electron runtime identity (default: Node host). The application version must match package.json and every embedded renderer file must match the validated dist fingerprint, including validation metadata.

Machine-readable evidence defaults to `tmp/native-validation-<platform>-<architecture>.json`; set `MOUNTEA_NATIVE_EVIDENCE_PATH` to choose a CI artifact path. Schema version 1 includes status, checks, runtime platform/architecture/version, release identity, inventory SHA-256, credential capability only, and persisted authored-record digest/counts. It never requests or exports credentials. Assertion failures write failed evidence and exit nonzero. Packaging/launcher failure evidence is separate from successful runtime evidence; no result implies signing or live-provider acceptance.

The expanded check uses a hidden, disposable user-data directory and blocks HTTP(S) in the native session. It verifies sandbox/preload/navigation boundaries; creates a project and dialogue through the real UI; adds a Delay node and saves with the platform shortcut; reads IndexedDB authoring records plus revision history; closes the native application completely; restarts the same executable/profile; reopens the graph; and compares all persisted records exactly. It reports a SHA-256 of those serialized records. No production test bridge or direct authoring-table writes are introduced. This is an authored graph/revision persistence test, not an audio import/export test. Uncaught renderer errors, renderer process failures, failed loads, and the storage initialization failure screen fail the check.
